# Thiết kế T5 — i18n hoàn chỉnh

## Bối cảnh & Mục tiêu
Hệ thống i18n cần hỗ trợ tự động nhận diện ngôn ngữ của hệ điều hành, đổi ngôn ngữ mà không cần khởi động lại, định dạng ngày giờ theo locale và múi giờ, giữ nguyên tính toàn vẹn của hợp đồng CLI JSON/exit code, và bổ sung tùy chọn thông báo giờ yên tĩnh (quiet hours).

## Chi tiết thiết kế

### 1. `language=auto` và Locale Detection
- `preferences.language` nhận các giá trị: `auto` (mặc định cho cài đặt mới), `vi`, `en`.
- `internal/i18n.DetectLocale()`:
  - Linux/Unix: Đọc theo thứ tự ưu tiên `LC_ALL`, `LC_MESSAGES`, `LANG`.
  - Windows: Gọi API Windows `GetUserDefaultLocaleName` (qua `golang.org/x/sys/windows`).
  - Quy tắc: Nếu locale bắt đầu bằng tiền tố `vi` (không phân biệt hoa thường) → `vi`; mọi trường hợp còn lại → `en`.
- `internal/i18n.Resolve(lang string) string`:
  - `auto` hoặc rỗng → chuyển sang `DetectLocale()`.
  - `vi*` → `vi`.
  - Còn lại → `en`.
- Kết quả `auto` không ghi đè vào DB (preference vẫn giữ giá trị `auto`).

### 2. Định dạng ngày giờ theo Locale & Múi giờ
- `internal/i18n.FormatTime(t time.Time, loc *time.Location, lang string) string`:
  - Tiếng Việt (`vi`): `02/01/2006 15:04`
  - Tiếng Anh / mặc định (`en`): `2006-01-02 15:04`
- `internal/i18n.FormatDate(t time.Time, loc *time.Location, lang string) string`:
  - Tiếng Việt (`vi`): `02/01/2006`
  - Tiếng Anh / mặc định (`en`): `2006-01-02`

### 3. Đổi ngôn ngữ không cần restart
- Tray định kỳ gọi `o.Language(ctx)` mỗi lần poll, cập nhật `a.lang` động.
- Lỗi và thông báo áp dụng ngôn ngữ tại thời điểm phát sinh.

### 4. Bất biến CLI JSON & Exit Code (Snapshot Guard)
- Lệnh CLI khi dùng cờ `--json` hoặc `--quiet` giữ nguyên 100% định dạng envelope tiếng Anh và mã exit code.
- Snapshot test kiểm tra các trường JSON, status code, error envelope không bị thay đổi bởi cài đặt ngôn ngữ.

### 5. Thông báo & Giờ yên tĩnh (Quiet Hours)
- Bổ sung tùy chọn `quiet_hours_start` và `quiet_hours_end` (định dạng `HH:MM`).
- Phương thức `Preferences.InQuietHours(t time.Time) bool` tính toán theo múi giờ `timezone` của preferences (hỗ trợ cả khung giờ qua nửa đêm, ví dụ `22:00` đến `07:00`). Khi trong giờ yên tĩnh, thông báo được chặn phát âm thanh/popup.
