# T5 — Application language and locale

Application preferences accept English, Vietnamese and automatic OS resolution.
Unix locale precedence is LC_ALL, LC_MESSAGES, then LANG; Windows uses its locale
API. Vietnamese prefixes resolve to Vietnamese; other locales use English. Auto
resolution does not overwrite the stored preference.

Human dates/times use saved timezone and locale. Vietnamese date order is day/month/
year; English uses year-month-day. Clients refresh language without requiring a
second engine or changing protocol keys.

JSON field names/timestamps, stable error codes and exit codes do not change with
language. CLI operational text remains the documented English contract; interactive
clients use bilingual catalogues. Names remain sanitized/escaped at presentation.

Quiet-hour preferences use local HH:MM windows, including overnight ranges.
Unsolicited Telegram messages defer; desktop notifications can be suppressed.
Public Markdown is English except README_VI.md; this does not remove Vietnamese
application support. See [i18n](../../internal/i18n), [CLI](../features/cli.md).
