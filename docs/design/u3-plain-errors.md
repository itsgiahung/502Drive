# U3 — Plain explanations

present.Explain is the single bilingual title / one-sentence message / action
catalogue. Stable codes stay intact. Unknown codes get generic advice and retain
the raw code, with no guessed cause. Reason remains an English CLI compatibility
entry point. HTTP failure and item DTOs add explanation (English, deterministic);
interactive clients localize by code. AST tests enumerate K1/provider constants
and literal item error writes so adding a code without an explanation fails.
No schema/engine/provider changes or new routes.
