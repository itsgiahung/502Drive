# Linux installation

English · [Tiếng Việt](install-linux_VI.md)

Use an RPM/DEB or archive from [Releases](https://github.com/itsgiahung/502Drive/releases).
Verify its checksum (and, from 0.4.5, its signature: see [Verify a release](#verify-a-release)) before installing. Packages are generated by
[GoReleaser](../.goreleaser.yaml); platform evidence is listed in [verification](verification.md).

```sh
sudo dnf install ./502drive_VERSION_linux_amd64.rpm
# Debian/Ubuntu:
sudo dpkg -i ./502drive_VERSION_linux_amd64.deb
```

Alternatively, the user-local installer verifies checksums and installs into
`~/.local/bin`:

```sh
curl -fsSL https://raw.githubusercontent.com/itsgiahung/502Drive/main/scripts/install.sh | sh
```

## Package contents

- `/usr/bin/502drive` and the `502d` shortcut.
- `/usr/lib/systemd/user/502drive.service`; installation does not enable it.
- Application-menu entry, icon and bash/zsh/fish completions.

## Initial setup

```sh
502drive setup --oauth-client /path/to/client_secret.json
502drive up
502drive account login
502drive destinations add FOLDER_LINK
502drive destinations default DESTINATION_ID
502drive doctor --online
```

`DESTINATION_ID` is the identifier returned by `destinations add/list`.
See [OAuth setup](oauth-setup.md). Optional Telegram setup uses a private bot-token
file and a synthetic-form numeric owner ID in examples; use your own values locally.

Configuration normally lives in `~/.config/502drive`, with data beside it.
Existing `~/.config/502drive-next` installations continue to work when the new
configuration does not exist. Do not rename that directory manually: configuration
may contain absolute paths into it.

## Background startup and tray

Choose one startup mechanism:

- `502drive autostart enable`: desktop login starts `502drive up --quiet`.
- `502drive autostart systemd install`: installs/enables a user unit with
  restart-on-failure. Use `systemctl --user start 502drive` to start it now.

The systemd unit restricts writes to documented application paths. A custom data
directory may require a `ReadWritePaths=` drop-in. Avoid enabling two startup
mechanisms; the instance lock prevents a second writer but duplicate launch attempts
are unnecessary.

The tray needs a desktop D-Bus session and StatusNotifier/AppIndicator support.
GNOME may need an AppIndicator extension. Without a tray host, use
`502drive menu`; the daemon and CLI still work. A plain line-menu fallback is
available with `--plain`, `NO_COLOR` or `TERM=dumb`.

## Inspect and maintain

```sh
502drive status
502drive doctor
502drive autostart systemd status
journalctl --user -u 502drive -f
```

Stop the daemon and back up before upgrades or offline maintenance. See the
[runbook](runbooks.md). Removing the package with `dnf remove` / `dpkg -r` leaves
user configuration and data intact. AppImage, Flatpak, Snap and armhf packages
are not provided.

## Verify a release

`checksums.txt` lists the SHA-256 of every archive and package, so it catches a
corrupted download. Since 0.4.5 each release also carries
`checksums.txt.sigstore.json`: a [Sigstore](https://www.sigstore.dev/) signature made
by this repository's release workflow. It proves the checksums came from that
workflow, not from someone who replaced the files. There is no signing key to steal:
the signature is tied to the workflow's identity by a short-lived certificate.

```sh
# 1. the signature on the checksums
cosign verify-blob \
  --bundle checksums.txt.sigstore.json \
  --certificate-identity-regexp '^https://github\.com/itsgiahung/502Drive/\.github/workflows/go-release\.yml@refs/tags/v.+$' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  checksums.txt

# 2. the checksums on your download
sha256sum --ignore-missing -c checksums.txt
```

`cosign` is free ([install](https://docs.sigstore.dev/cosign/installation/)). The
Windows installer (`502drive-setup.exe`) has its own `.sha256` file and is not yet
code-signed, so Windows shows an "unknown publisher" notice. `502drive update
--install` checks the checksum only; to require the signature, install with the
script and `REQUIRE_SIGNATURE=1`. Releases before 0.4.5 have no signature.
